# knowyourbar.com — Project README & Claude Briefing

A protein bar search and filter tool at **knowyourbar.com**. Users can search, filter, and compare 541+ protein bars by macros, ingredients, dietary certifications, and ingredient quality scores. The database is hand-researched by the owner and is the core proprietary asset of the site.

---

## Tech Stack

- **Plain HTML/CSS/JS** — no frameworks, no build process
- **Hosted on Cloudflare Pages** — free, auto-deploys when GitHub is updated
- **GitHub repo** — source of truth for all deployed files
- **Domain** — knowyourbar.com registered on GoDaddy, DNS managed by Cloudflare

## How to Add New Bars and Update the Site

**Step 1** — Add rows to the `BarDB` sheet in your Excel database. Fill in all macros, certifications, ingredients, and website URL.

**Step 2** — Upload both files to Claude: your bar database Excel and `knowyourbar_scoring_schema.xlsx`.

**Step 3** — Say "run score_and_export". Claude runs the full scoring pipeline and returns a new `bars.js`.

**Step 4** — If new brands were added, update the `BRAND_LIST` array in `app.js`. Tell Claude which brands are new and it will update the list.

**Step 5** — Upload `bars.js` (and `app.js` if brands changed) to GitHub. Cloudflare auto-deploys in ~60 seconds.

**Note:** If files don't appear updated after uploading, delete them from GitHub first, then re-upload. This clears a GitHub caching quirk.

## Ingredient Scoring System

This is the most important part of the project. Everything is documented in the `Scoring_Logic` sheet of `knowyourbar_scoring_schema.xlsx`.

### How scores are calculated

Each bar's ingredient list is parsed into individual ingredients mapped to canonical names, each with a base score from -4 (harmful) to +4 (excellent). The base score is weighted by ingredient position — earlier ingredients are present in greater quantities and contribute more to the final score.

**Final Score** = Sum of (base_score x position_weight) for each ingredient + count adjustment

### Position weights

| Position | Weight | Position | Weight |
|---|---|---|---|
| 1st | 1.00 | 6th | 0.44 |
| 2nd | 0.85 | 7th | 0.37 |
| 3rd | 0.72 | 8th | 0.31 |
| 4th | 0.61 | 9th | 0.26 |
| 5th | 0.52 | 10th+ | Decreasing from 0.22 |

### Ingredient count adjustment

| Count | Adjustment |
|---|---|
| 8 or fewer | +0.05 |
| 9-12 | 0.00 |
| 13-16 | -0.05 |
| 17-20 | -0.10 |
| 21+ | -0.15 |

### Score bands

| Grade | Label | Score Range |
|---|---|---|
| A | Clean | >= 8.0 |
| B | Good | 4.0 to 7.9 |
| C | Okay | 0.0 to 3.9 |
| D | Poor | -3.0 to -0.1 |
| F | Avoid | Below -3.0 |

### Schema version

The current schema (`knowyourbar_scoring_schema.xlsx`) is **v2**:
- 1,011 canonical ingredients — all vetted with base scores and categories
  - 686 originally scored (auto_v1)
  - 319 newly scored in v2 (vetted_v2)
  - 6 parsing artifacts scored 0 (auto_v2)
- 1,968 alias mappings from raw label text to canonicals
- Pre-parsed ingredient lines for all 541 original schema bars
- Full Scoring_Logic sheet documenting every rule

### How new bars are scored

Bars in the schema are scored using pre-parsed ingredient lines with full position and clause weighting. New bars added to your Excel are auto-scored from raw ingredient text using alias and canonical fuzzy matching. Both paths produce a score, band, insight chips, and positive/concern ingredient lists.

### Insight chips

Colored chips shown in the expand row highlight specific characteristics. Every chip has an exact, deterministic rule.

| Chip | Type | Rule |
|---|---|---|
| Protein Leads | Positive (green) | First ingredient position is protein category |
| Quality Protein Source | Positive (green) | High-quality protein (base_score >= 3) in top 5 positions |
| Whole Food Forward | Positive (green) | 2+ of first 3 positions are whole_food category |
| Short Clean List | Positive (green) | 8 or fewer scored ingredients |
| Fortified | Neutral (gray) | Vitamin/mineral ingredients present |
| Long Ingredient List | Neutral (gray) | 18 or more scored ingredients |
| Artificial Sweeteners | Concern (orange) | Full ingredient text contains sucralose, acesulfame, aspartame, or saccharin |
| Sugar Alcohols | Concern (orange) | Sugar alcohol canonical present in any position |
| Sugar Alcohol Early | Concern (orange) | Sugar alcohol in top 5 positions |
| Processed Oils | Concern (orange) | Full text contains palm oil, palm kernel oil, canola oil, soybean oil, or hydrogenated oils (high-oleic excluded) |
| Sweetener Heavy | Concern (orange) | Sweetener category in top 3 positions |
| Collagen Protein | Concern (orange) | First protein ingredient is collagen |

**Important:** Chip detection scans the full raw ingredient text including "contains less than" clauses. A bar is flagged for artificial sweeteners even if sucralose appears at trace levels. The numeric score still correctly excludes trace ingredients from the calculation.

### Key scoring decisions

Sugar alcohols are NOT classified as artificial sweeteners. The "No Artificial Sweeteners" preset excludes sucralose, acesulfame, aspartame, saccharin, and maltitol. The "Least Sugar" preset separately handles sugar alcohol exclusion. This is intentional — users can control each category independently.

## Filter Panel

### Quick Filter Presets

| Preset | Logic | Sort |
|---|---|---|
| High Protein Low Calorie | Protein calories >= 40% of total calories | Efficiency descending |
| High Protein, No Artificial Sweeteners | Protein >= 15g, no sucralose/acesulfame/aspartame/saccharin/maltitol | Protein descending |
| High Protein, Least Sugar | Protein >= 15g, sugar alcohol = 0 | Sugars ascending |
| High Fiber, Low Sugar | Fiber >= 8g, sugars <= 5g | Fiber descending |

Presets do NOT move the sliders. They filter independently as a separate control layer.

## Key Decisions

| Decision | Rationale |
|---|---|
| Plain HTML/JS, no framework | No build process, no dependencies, maintainable via Claude |
| Client-side filtering | All bars in bars.js, instant results, no server needed |
| Scores baked into bars.js at export time | No runtime computation, fast page load |
| Full text scan for chip flags | Honest disclosure — flags trace ingredients; score still excludes them |
| Sugar alcohols separate from artificial sweeteners | Technically correct, gives users independent control |
| Title case for ingredient lists | Matches real nutrition label convention |
| "No BS" in hero copy | Matches bar packaging, honest brand voice, doesn't constrain future monetization |
