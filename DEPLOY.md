## Standard Bar Database Update

Use this when adding new bars, updating affiliate links, or fixing ingredient data.

### Step by step

1. Update your bar database Excel (add bars, fix ingredients, add affiliate links)
2. Run the scoring pipeline locally:

```bash
python3 score_and_export.py \
    --db "KYB - New Protein Bar Database (2026).xlsx" \
    --schema "knowyourbar_scoring_schema_v3.xlsx"
```

3. Review the output — check grade distribution and unscored bars
4. Upload `bars.js` to GitHub
5. If the bar count changed, also update the count in all HTML files (search and replace the old number)
6. Cloudflare deploys in ~60 seconds

### Files required every time
- Your bar database Excel (BarDB sheet)
- `knowyourbar_scoring_schema_v3.xlsx` — the alias and canonical tables

The schema's Ingredient_Lines and Products sheets are NOT used. Only Canonical_Ingredients and Alias_Map are loaded. The pipeline scores everything from raw ingredient text using a single unified path.

### Running via Claude instead
If you don't want to run the script locally, upload both files to Claude and say "run score_and_export". Claude will run the same pipeline and output bars.js.

## How the Pipeline Works

Every bar is scored from its raw ingredient text. No pre-parsed data is used.

1. Ingredient string is parsed into top-level and sub-ingredients
   - Top-level ingredients (e.g. "Dates, Egg Whites, Almonds") get full weight
   - Sub-ingredients inside parentheses (e.g. protein blends) get 60% weight — they are present in smaller amounts than their parent
2. Each ingredient is looked up in the alias map → canonical ingredient
3. Each canonical has a base score from -4 (harmful) to +4 (excellent)
4. Score = sum of (base_score × position_weight × sub_multiplier) + count adjustment
5. Insight chips are generated for every scored bar using the same logic

### Grade bands
| Grade | Label | Score range |
|-------|-------|-------------|
| A | Clean | ≥ 8.0 |
| B | Good | 4.0 – 7.9 |
| C | Okay | 0.0 – 3.9 |
| D | Poor | -3.0 to -0.1 |
| F | Avoid | Below -3.0 |

## Adding a New Brand Review Page

1. Run the pipeline to get a fresh bars.js
2. Tell Claude: "Generate a brand review page for [Brand Name]"
3. Download the HTML file
4. Update the nav dropdown on ALL existing pages (nav is inline in each HTML file)
5. Add the new page to sitemap.xml
6. Upload all changed files to GitHub
7. Request indexing in Google Search Console

## Updating the Scoring Schema

When adding new canonical ingredients or adjusting scores:

1. Edit `knowyourbar_scoring_schema_v3.xlsx`
   - Add rows to `Canonical_Ingredients`
   - Add rows to `Alias_Map`
2. Re-run the pipeline
3. Review the grade distribution — compare to current (A=86 B=282 C=266 D=158 F=21)
4. Upload bars.js

## Google Search Console

After uploading new or significantly changed pages:
1. Go to Search Console for knowyourbar.com
2. Paste the URL into the URL inspection bar
3. Click "Request Indexing"
4. If new pages were added, re-submit sitemap.xml (Sitemaps section in left nav)
